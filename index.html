ジャイロOFFカメラ

傾きセンサー（ジャイロ）を見ない正方形カメラです。真下に向けて撮っても、写真の向きが勝手に横になったり逆さになったりしません。枠の中を、画面に映っているとおりに保存します。

はじめて開くとカメラの使用許可を聞かれます。「許可」を選んでください。

Safariの共有ボタン →「ホーム画面に追加」で、ふつうのアプリのように使えます。

写真

「◯枚を保存」→ 共有メニューの「画像を保存」で、写真アプリに入ります。

まだ写真がありません

保存がうまくいかないときは、写真を長押し →「"写真"に追加」でも保存できます。

設定と使い方

向きを固定する
本体をどう持っていても、画面が回転しても、写真はいつも同じ向き（縦持ちの向き）で保存します。オフにすると、画面に見えている向きそのままで保存します。
シャッター音
撮影のときに「カシャッ」と鳴らします。iPhoneがマナーモード（消音スイッチがオン）のときは鳴りません。
画像のサイズ
正方形の一辺のピクセル数。「標準」がいちばん速く軽く動きます。ネット出品用なら標準で十分です。「高画質」はカメラを重い設定で開くので、起動と動作が遅くなります。
背景を消したら元の写真を消す
背景なしの写真だけが残ります。写真アプリに保存ずみの元写真は消えません。
背景を消したあとの背景
「白」は出品写真向け（JPEG）。「透明」は合成用（PNG）。
背景除去の精度
「きれい」がおすすめ。部品は約88MB。「速い」は約44MBで軽いぶん、境目が荒れることがあります。
背景除去はこのiPhoneの中で動きます。はじめて使うときだけAIの部品をダウンロードします（Wi-Fi推奨）。iPhoneのGPUが使えれば1枚数秒、使えないときは10〜40秒かかります。
画質
「高」は商品写真向け。ファイルは大きくなります。
カメラの解像度
カメラを開くと表示されます
起動の記録
カメラを開くと表示されます
起動が遅いときは、この行を読み上げるか画面写真で教えてください。

このアプリの仕組み

  • iPhone標準のカメラは、傾きセンサーで「どっちが上か」を判断して写真を回転させます。真下に向けて撮ると、この判断がぶれて横や逆さになります。
  • このアプリは傾きセンサーを一切見ません。カメラの映像をそのまま画像にするので、向きの情報（EXIFの回転）も付きません。

使い方

  1. 白い枠の中が正方形の写真になります。まん中の白いボタンで撮影。何枚でも続けて撮れます。
  2. 左下のサムネイルから一覧を開き、「まとめて保存」。
  3. 出てきた共有メニューで「画像を保存」を選ぶと、写真アプリに全部入ります。
  4. 背景を消したいときは、一覧の「まとめて背景を消す」。1枚だけなら写真を開いて「背景を消す」。元の写真は自動で消え、背景なしの写真に置き換わります（設定で残すこともできます）。処理中は画面を消さないでください。

もっときれいに背景を消すには（Apple純正・おすすめ）

  • iPhoneに入っている背景削除は、このアプリのAIより精度が高く、速いです。「ショートカット」アプリに次の1本を入れると、写真アプリから複数枚まとめて使えます。
  • ショートカット「背景を削除」を入れる（Safariで開き、「ショートカットを追加」を押す）
  • 使い方：写真アプリで写真を複数選ぶ → 共有ボタン → 「背景を削除」。背景が透明になった写真が写真アプリに保存されます。
  • 白背景にしたいときは、このアプリの一覧で「透明の写真を白背景にする」→ その写真を選ぶ → 保存。

注意

  • 撮った写真はこの端末のブラウザ内に一時保存されます。保存が終わるまでSafariの履歴やサイトデータを消さないでください。
  • ズームや露出の調整はできません。明るい場所で、距離を取って撮ってください。
